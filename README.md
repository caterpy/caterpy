A simple, colorful starter project for learning the basics of GitHub Desktop, editing files, and managing your work with version control.

## ✨ What you'll practice

- editing files locally
- creating clean commits
- reviewing diffs
- pushing updates to GitHub

## 🧭 Quick start

1. Open the project in GitHub Desktop
2. Make a change to a file
3. Review the diff
4. Commit your update
5. Push it to GitHub

## 🎯 Purpose

This repo is designed to help beginners get comfortable with the everyday workflow of collaborative coding without feeling overwhelmed.

Welcome to the Desktop Tutorial project — a simple starter repo for learning how to work with GitHub Desktop, make file edits, and manage version control with confidence.

## ✨ About this project

This project is designed to help you practice the basics of:

- editing files locally
- making commits
- reviewing changes
- pushing updates to GitHub

## 🧭 Quick workflow

1. Open the project in GitHub Desktop
2. Edit the files you want to change
3. Review the diff
4. Commit your work
5. Push to GitHub
